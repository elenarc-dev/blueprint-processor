# Release 0.1.0

## Objective

Dejar el repositorio listo para publicar la versión `0.1.0`: versiones
coherentes en los tres manifiestos, changelog final con fecha y un build de
producción verificado.

## Work Completed

- `src-tauri/tauri.conf.json` pasa de `1.0.0` (resto del scaffold) a `0.1.0`,
  la misma versión que `package.json` y `src-tauri/Cargo.toml`. Tauri toma este
  valor para el nombre de los artefactos y para el updater.
- `docs/changelog/0.1.0.md` abre con la fecha de release y un resumen de la
  entrega; el detalle por `Added` / `Fixed` / `Changed` / `Known issues` ya
  estaba al día con los últimos commits.
- `docs/README.md` enlaza el changelog de la versión en la navegación rápida.
- Tag anotada local `v0.1.0` sobre el commit de release (no publicada).

## Current State & Verified Behavior

Comandos ejecutados en este árbol, con el resultado observado:

- `pnpm check` → `svelte-check found 0 errors and 3 warnings in 2 files`
  (los tres avisos a11y preexistentes de `Palette.svelte` y
  `dashboard/+page.svelte`).
- `pnpm build` → exit 0; `@sveltejs/adapter-static` escribe el sitio en
  `build/`, que es el `frontendDist` que consume Tauri.
- `pnpm dev --port 5199` + Chromium headless vía CDP → la app arranca sin
  cuelgue del hilo principal, sin `effect_update_depth_exceeded` y con
  Toolbar, Palette y canvas renderizados.
- `cd src-tauri && cargo test --lib` → `295 passed; 0 failed` tras corregir
  `file_iterate_folder` (PROD-TECH-007, cerrada).

## Problems & Blockers

- No se generó el bundle de escritorio: `pnpm tauri build` compila Rust en
  release (rig-core, image, reqwest) y necesita las dependencias de sistema de
  WebKitGTK; queda fuera de esta preparación y sin verificar aquí.
- `file_iterate_folder` estaba roto de origen: sus tests pasaban una ruta de
  fichero a `fs::read_dir` y el executor hacía `unwrap()` sobre la ruta. Se
  corrigió después de escribir este informe; la suite Rust ya está en verde.
- Las funciones nuevas de subgrafos (navegación, agrupado, entradas
  reconectadas, Inspector) no se ejercitaron en runtime Tauri en esta sesión:
  solo typecheck, build y arranque en navegador.

## Next Steps

1. Ejecutar `pnpm tauri build` en cada plataforma objetivo y probar el
   instalador resultante.
2. Publicar la tag `v0.1.0` y adjuntar los artefactos cuando el bundle esté
   verificado.
3. Mantener `cargo test --lib` en verde en CI antes de cada release.
