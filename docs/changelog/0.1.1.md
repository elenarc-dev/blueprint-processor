# 0.1.1

Release: **2026-11-21**. Parche sobre `0.1.0`: la suite Rust vuelve a estar en
verde y `file.iterate` ya no aborta un run con un panic. Versión alineada en
`package.json`, `src-tauri/Cargo.toml` y `src-tauri/tauri.conf.json`.

## Fixed

- `file.iterate` (`file_iterate_folder.rs`): el módulo se documentaba como
  `file.read` y sus tests pasaban una ruta de *fichero* a `fs::read_dir`, así
  que tres de ellos fallaban siempre con `Not a directory (os error 20)`.
  Ahora la cabecera describe el nodo real y los tests escanean un directorio
  temporal (ficheros, subcarpetas, carpeta vacía, input cableado que gana al
  param), incluido un test de regresión para la ruta de fichero.
- El executor ya no hace `unwrap()` sobre la ruta: vacía, ausente o no-string
  devuelven `ExecError::Node` con el nodo y el path en el mensaje. La ruta se
  recorta y las entradas con nombre no-UTF-8 se saltan con un `warn` en el log
  del run en vez de abortar el escaneo completo.
- `docs/TASKS.md`: PROD-TECH-007 cerrada.

## Verified

- `cd src-tauri && cargo test --lib` → `295 passed; 0 failed`.
- `rustfmt --edition 2021 --check src-tauri/src/executor/nodes/file_iterate_folder.rs` → sin cambios.

## Known issues

- Los mismos que `0.1.0` (ver [`0.1.0.md`](0.1.0.md)): sin cancelación de un run
